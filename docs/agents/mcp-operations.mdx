The [Polar MCP server](/integrate/mcp) can call 108 Polar API operations. Your agent finds them with the `search` tool and calls them with `execute`. With `?codemode=false` on the server URL, each operation is its own tool instead.

Operations are named `{resource}_{action}`, like `customers_get_state_external`. The [Polar CLI](/integrate/cli/resources) uses the same names: `customers_get_state_external` is `polar customers get_state_external`, and `customers_members_list` is `polar customers members list`.

<Note>
  The MCP server calls the Polar API with `Polar-Version: 2027-01`, the [next API version](/api-reference/next/introduction). Request and response bodies follow the 2027-01 schema, which can differ from the 2026-10 examples elsewhere in these docs. Operations marked † exist only in 2027-01.
</Note>

In [read-only mode](/integrate/mcp#read-only-mode) (`?readonly=true`), only `GET` operations work.

<Visibility for="agents">
  Use these names in `execute` code and when you tell the user which operation a prompt uses. Don't invent operations that aren't listed here. For anything below under "Not available", use the API or SDK, or point the user to the dashboard.
</Visibility>

## Not available from the MCP server

These have no MCP operation. Use the API, an SDK or the dashboard:

- Creating or updating Checkout Sessions, and creating customer sessions (Customer Portal links).
- Ingesting or listing events.
- Creating subscriptions. Creating, finalizing or exporting orders.
- Creating or updating organizations, including every setting.
- Uploading files. Validating, activating or deactivating license keys.
- Disputes.
- Creating or revoking organization access tokens.
- Balance, payouts, payout accounts, transactions, taxes, organization members, SSO and domains (dashboard only).

## Products

| Operation | Request | Description |
| --- | --- | --- |
| `products_list` | `GET /v1/products/` | List products. |
| `products_create` | `POST /v1/products/` | Create a product. |
| `products_get` | `GET /v1/products/{id}` | Get a product by ID. |
| `products_update` | `PATCH /v1/products/{id}` | Update a product. |
| `products_delete` | `DELETE /v1/products/{id}` | Delete a product that has no orders, subscriptions, trials or discounts. Archive it otherwise. |
| `products_update_benefits` | `POST /v1/products/{id}/benefits` | Update benefits granted by a product. |
