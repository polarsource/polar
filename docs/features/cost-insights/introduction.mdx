**Cost insights** puts what you spend next to what you earn. Attach a cost to the events you already send, and Polar reports costs, gross margin and cashflow, overall and per customer. Revenue comes from your orders. Costs come from your events.

Typical costs: LLM calls, GPU minutes, storage, email and SMS sends.

The examples on this page use the sandbox and API version `2026-10`. See [Usage](/concepts/usage) for how events work.

## Cost events

Add a `_cost` object to an event's `metadata`. For LLM calls, add `_llm` too, so costs can be broken down by model and vendor.

<CodeGroup>
```typescript TypeScript
await polar.events.ingest({
  events: [
    {
      name: "ai_usage",
      external_customer_id: "user_123",
      metadata: {
        total_tokens: 77,
        _cost: { amount: 0.0014, currency: "usd" },
        _llm: {
          vendor: "openai",
          model: "gpt-4.1-nano",
          input_tokens: 58,
          output_tokens: 19,
          total_tokens: 77,
        },
      },
    },
  ],
});
```

```python Python
polar.events.ingest(
    events=[
        {
            "name": "ai_usage",
            "external_customer_id": "user_123",
            "metadata": {
                "total_tokens": 77,
                "_cost": {"amount": 0.0014, "currency": "usd"},
                "_llm": {
                    "vendor": "openai",
                    "model": "gpt-4.1-nano",
                    "input_tokens": 58,
                    "output_tokens": 19,
                    "total_tokens": 77,
                },
            },
        }
    ]
)
```

```bash cURL
curl -X POST https://sandbox-api.polar.sh/v1/events/ingest \
  -H "Authorization: Bearer $POLAR_ACCESS_TOKEN" \
  -H "Polar-Version: 2026-10" \
  -H "Content-Type: application/json" \
  -d '{
    "events": [
      {
        "name": "ai_usage",
        "external_customer_id": "user_123",
        "metadata": {
          "total_tokens": 77,
          "_cost": { "amount": 0.0014, "currency": "usd" },
          "_llm": {
            "vendor": "openai",
            "model": "gpt-4.1-nano",
            "input_tokens": 58,
            "output_tokens": 19,
            "total_tokens": 77
          }
        }
      }
    ]
  }'
```
</CodeGroup>

In production, send events with `polar.metering()`. See [Send events](/features/usage-based-billing/event-ingestion#send-events-in-production).

### `_cost`

| Field | Required | Description |
| --- | --- | --- |
| Yes | `amount` | The cost **in cents**, as a decimal. Up to 17 digits, 12 after the decimal point. |
| Yes | `currency` | `usd`. No other currency is supported. |

The amount is in cents, not dollars: `150` is $1.50, and `0.0014` is $0.000014. Fractions of a cent are kept, so you can record the cost of a single API call.

### `_llm`

| Field | Required | Description |
| --- | --- | --- |
| Yes | `vendor` | The provider, such as `openai` |
| Yes | `model` | The model, such as `gpt-4.1-nano` |
| Yes | `input_tokens` | Input tokens |
| Yes | `output_tokens` | Output tokens |
| Yes | `total_tokens` | Total tokens |
| No | `cached_input_tokens` | Input tokens served from cache |
| No | `prompt` | The prompt |
| No | `response` | The response |

These two are the only nested objects metadata accepts. A meter can read inside them with a dot path, like `_cost.amount` or `_llm.total_tokens`.

The [LLM strategy](/features/usage-based-billing/ingestion-strategies/llm-strategy) adds `_llm` for you, and `_cost` when you give it a `.cost()` function. Other [ingestion strategies](/features/usage-based-billing/ingestion-strategies/ingestion-strategy) accept `.cost()` too.

## Traces

One user action often costs several things: an agent run makes three LLM calls and a web search. Send each as an event, and link them with `parent_id` so their costs add up under one **trace**.

1. Send the root event with your own `external_id`, such as a request ID.
2. Send each child with `parent_id` set to that `external_id`, or to the root event's Polar ID.

```json
{
  "events": [
    {
      "name": "agent_run",
      "external_customer_id": "user_123",
      "external_id": "req_8f2c"
    },
    {
      "name": "ai_usage",
      "external_customer_id": "user_123",
      "parent_id": "req_8f2c",
      "metadata": { "_cost": { "amount": 0.0014, "currency": "usd" } }
    },
    {
      "name": "web_search",
      "external_customer_id": "user_123",
      "parent_id": "req_8f2c",
      "metadata": { "_cost": { "amount": 0.5, "currency": "usd" } }
    }
  ]
}
```

Children can arrive before their parent. Polar holds them until the parent arrives. If it never does, they aren't processed, so always send the root.

In **Analytics → Costs**, the event type page for `agent_run` adds up the costs of its children, so you see what a whole run costs.

If you trace with OpenTelemetry, the `PolarTraceExporter` sends spans as events with the parent links already set. See [OpenTelemetry](/features/usage-based-billing/ingestion-strategies/ingestion-strategy#opentelemetry).

## Where costs show up

<Note>
  Dashboard only, except the metrics below, which the API, CLI and MCP server can read.
</Note>

**Analytics → Costs** has two tabs:

- **Overview**: the cost metrics as charts, then:
  - **Breakdown**: event types ranked by total spend in the period.
  - **Changes**: the biggest cost movers compared to the previous period.
  - **By Customer**: customers ranked by total cost.
  - **Anomalies**: individual traces whose total cost is at or above the 99th percentile for their event type.
- **LLM**: costs from events with `_llm`, ranked **By Model**, **By Vendor** and **By Customer**.

Select an event type to see its **Occurrences**, **Total Cost**, **Average Cost** and **Cost per Customer** over time.

**Analytics → Events** has a **Cost** filter to show only events that carry a cost.

**Customers → Cost Drivers** ranks customers by their share of your costs. See [Customer analytics](/features/customer-analytics#cost-drivers).

## Cost metrics

These metrics come from your `_cost` data and your revenue. Find them as charts on **Analytics → Costs** and in the **Costs** and **Usage** groups on **Analytics → Metrics**. Amounts are in cents.

| Name | Slug | Definition |
| --- | --- | --- |
| Costs | `costs` | Sum of `_cost.amount` on your events in each period |
| Cumulative Costs | `cumulative_costs` | Running total of `costs` |
| Cost Per User | `cost_per_user` | Costs divided by active subscriptions |
| Gross Margin | `gross_margin` | Cumulative revenue minus cumulative costs |
| Gross Margin % | `gross_margin_percentage` | Gross margin as a share of cumulative revenue |
| Cashflow | `cashflow` | Revenue minus costs in each period |
| Active User (By event) | `active_user_by_event` | Distinct customers who sent events in the period |

**Lifetime Value** (`ltv`) also subtracts cost per user from revenue per user. See [Metrics](/features/analytics) for every metric.

<CodeGroup>
```typescript TypeScript
const metrics = await polar.metrics.get({
  start_date: "2026-11-01",
  end_date: "2026-11-30",
  interval: "day",
  metrics: ["costs", "gross_margin", "cashflow"],
});
```

```python Python
metrics = polar.metrics.get(
    start_date="2026-11-01",
    end_date="2026-11-30",
    interval="day",
    metrics=["costs", "gross_margin", "cashflow"],
)
```

```bash cURL
curl -G https://sandbox-api.polar.sh/v1/metrics/ \
  -H "Authorization: Bearer $POLAR_ACCESS_TOKEN" \
  -H "Polar-Version: 2026-10" \
  --data-urlencode "start_date=2026-11-01" \
  --data-urlencode "end_date=2026-11-30" \
  --data-urlencode "interval=day" \
  --data-urlencode "metrics=costs" \
  --data-urlencode "metrics=gross_margin" \
  --data-urlencode "metrics=cashflow"
```
</CodeGroup>

Pass `customer_id` to get one customer's costs and margin.

## From the CLI or your agent

Costs are sent with events, from your application. Reading them works everywhere:

| Task | CLI | MCP operation |
| --- | --- | --- |
| Read cost metrics | `polar metrics get --start-date 2026-11-01 --end-date 2026-11-30 --interval day --metrics costs --metrics gross_margin` | `metrics_get` |
| Read one event and its `_cost` | `polar events get <id>` | `events_get` |

```text Prompt
What were my costs and gross margin in my Polar sandbox organization last month?
```
