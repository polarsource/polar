[Encore](https://encore.dev) is an open source backend framework for TypeScript with built-in infrastructure automation and observability. When you define services, databases, and APIs in code, Encore automatically provisions and manages the underlying infrastructure, both locally and in the cloud.

Because Encore defines infrastructure in code and traces every request, a coding agent can read your Polar integration and inspect the trace of a checkout or webhook to debug it.

This guide adds a checkout endpoint and a webhook handler to an Encore app, using the [TypeScript SDK](/integrate/sdk/typescript) and API version `2026-10`. Build against the [sandbox](/integrate/sandbox) first. Nothing there moves real money.

## Examples

- [With Encore](https://github.com/polarsource/examples/tree/main/with-encore)

## Install the SDK

```bash Terminal
npm install @polar-sh/sdk
```

## Set the secrets

Encore manages secrets the same way locally and in the cloud.

### Access token and environment

Create an [organization access token](/integrate/oat) in your sandbox organization's **Settings → Access Tokens**, or run `polar auth token`. Add it to Encore, along with `POLAR_MODE` set to `sandbox`:

```bash Terminal
encore secret set --type local POLAR_ACCESS_TOKEN
encore secret set --type local POLAR_MODE
```

You'll add `POLAR_WEBHOOK_SECRET` in [Receive webhooks](#receive-webhooks). When you deploy to Encore Cloud, set production secrets in its dashboard or your CI pipeline.

## Create an API client

Create the client with `createPolar`, reading the token and environment from Encore's secrets:

```tsx title="payments/polar.ts"
import { createPolar } from "@polar-sh/sdk/2026-10";
import { secret } from "encore.dev/config";

const POLAR_MODE = secret("POLAR_MODE");
const POLAR_ACCESS_TOKEN = secret("POLAR_ACCESS_TOKEN");

export const polar = createPolar({
  accessToken: POLAR_ACCESS_TOKEN(),
  environment: POLAR_MODE() as "sandbox" | "production",
});
```

Set `POLAR_MODE` to `production`, with a production token, when you go live.

## Add a checkout endpoint

This endpoint creates a Checkout Session and redirects the customer to it:

```tsx title="payments/payments.ts"
import { api, APIError } from "encore.dev/api";
import { polar } from "./polar";

export const checkout = api.raw(
  { expose: true, path: "/checkout", method: "GET" },
  async (req, resp) => {
    const url = new URL(req.url!, `http://${req.headers.host}`);
    const productId = url.searchParams.get("product");

    if (!productId) {
      resp.writeHead(400);
      resp.end("Missing product query parameter");
      return;
    }

    try {
      const result = await polar.checkouts.create({
        products: [productId],
        success_url: "https://your-app.com/confirmation?checkout_id={CHECKOUT_ID}",
      });

      resp.writeHead(302, { Location: result.url });
      resp.end();
    } catch (error) {
      console.error("[Polar] Checkout error:", error);
      resp.writeHead(500);
      resp.end("Failed to create checkout session");
    }
  }
);
```

Visit `/checkout?product=<product_id>` to start a checkout. To link the customer to your user, also pass `external_customer_id` to `checkouts.create`.

## Receive webhooks

Webhooks keep your app in sync with checkouts, orders and subscriptions.

### Forward webhooks locally

The [Polar CLI](/integrate/cli/webhooks) forwards your sandbox organization's webhooks to your Encore app:

```bash Terminal
polar auth login --sandbox
polar webhook listen http://localhost:4000/webhooks/polar
```

Set the secret it prints as `POLAR_WEBHOOK_SECRET`:

```bash Terminal
encore secret set --type local POLAR_WEBHOOK_SECRET
```

When you deploy, [create a webhook endpoint](/integrate/webhooks/endpoints) in **Settings → Webhooks** for `https://<your-domain>/webhooks/polar` and set that endpoint's secret in Encore Cloud.

### Add the webhook handler

Use `api.raw()` so the handler gets the raw request body, which signature verification needs. `webhooks.validateEvent` verifies the signature and returns a typed event:

```tsx title="payments/webhooks.ts"
import { api } from "encore.dev/api";
import { secret } from "encore.dev/config";
import { webhooks } from "@polar-sh/sdk/2026-10";

const POLAR_WEBHOOK_SECRET = secret("POLAR_WEBHOOK_SECRET");

export const polarWebhooks = api.raw(
  { expose: true, path: "/webhooks/polar", method: "POST" },
  async (req, resp) => {
    const chunks: Buffer[] = [];
    for await (const chunk of req) {
      chunks.push(chunk);
    }
    const body = Buffer.concat(chunks).toString("utf-8");

    const headers: Record<string, string> = {};
    for (const [key, value] of Object.entries(req.headers)) {
      headers[key] = Array.isArray(value) ? value[0] : (value ?? "");
    }

    let event: webhooks.WebhookPayload;
    try {
      event = await webhooks.validateEvent(body, headers, POLAR_WEBHOOK_SECRET());
    } catch (error) {
      if (error instanceof webhooks.PolarWebhookVerificationError) {
        resp.writeHead(403);
        resp.end();
        return;
      }
      if (error instanceof webhooks.PolarWebhookUnknownTypeError) {
        resp.writeHead(202);
        resp.end();
        return;
      }
      throw error;
    }

    switch (event.type) {
      case "order.paid":
        console.log("[Polar] Order paid:", event.data.id);
        break;
      case "customer.state_changed":
        console.log("[Polar] Customer state changed:", event.data.id);
        break;
    }

    resp.writeHead(202);
    resp.end();
  }
);
```

See [Handle deliveries](/integrate/webhooks/delivery) for retries and timeouts, and [Webhook events](/integrate/webhooks/events) for every event type.

## Run it locally

Start your Encore app:

```bash Terminal
encore run
```

Encore's local development dashboard at `localhost:9400` lets you:

- View traces for every request, including checkout redirects and webhook deliveries
- Inspect API calls between services
- Query local databases
- View logs and errors as they happen

## Deploy to production

Deploy to Encore Cloud or your own cloud account:

```bash Terminal
git push encore
```

Encore provisions the infrastructure your app needs. Then:

1. Set production secrets in the Encore Cloud dashboard, with `POLAR_MODE` set to `production`
2. Create a webhook endpoint in your production organization for your production domain
3. Update `success_url` to your production URL
