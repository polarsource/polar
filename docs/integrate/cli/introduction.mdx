The Polar CLI brings your Polar organization to your terminal. It does three jobs:

- **Manage resources.** Commands for 22 API resources, from products and customers to meters and webhook endpoints. See [Resource commands](/integrate/cli/resources).
- **Test webhooks.** Forward your organization's webhooks to your local server and trigger sample events. See [Webhooks](/integrate/cli/webhooks).
- **Set up agents.** `polar agent setup` installs the Polar plugin, MCP servers and skills for Claude Code, Codex and Cursor. See [Skills and plugins](/agents/skills-and-plugins).

## Installation

The CLI ships as a single binary for macOS (Apple Silicon and Intel), Linux (x64 and arm64) and Windows (x64).

<Tabs>
  <Tab title="macOS and Linux">
    ```bash Terminal
    curl -fsSL https://polar.sh/install.sh | bash
    ```

    The script installs `polar` to `~/.polar/bin` and adds it to your `PATH`.
  </Tab>
  <Tab title="Windows">
    In PowerShell:

    ```powershell PowerShell
    irm https://polar.sh/install.ps1 | iex
    ```

    The script installs `polar.exe` to `%USERPROFILE%\.polar\bin` and adds it to your user `PATH`. Restart other open terminals to pick it up.
  </Tab>
  <Tab title="Package managers">
    On any platform. pnpm and bun block install scripts by default, and the flags below allow the one that unpacks the binary:

    ```bash Terminal
    npm install -g @polar-sh/cli
    pnpm add -g --allow-build=@polar-sh/cli @polar-sh/cli
    bun install -g --trust @polar-sh/cli
    ```
  </Tab>
</Tabs>

Check that it works:

```bash Terminal
polar --version
```

Then sign in to the sandbox:

```bash Terminal
polar auth login --sandbox
```

Run `polar` with no arguments to see the version, the environments you're signed in to and the active organization.

## Updating

The CLI checks for new releases in the background and tells you when one is
available. Install it with:

```bash Terminal
polar update
```

`polar update` detects how the CLI was installed. Override it with `--method` (`binary`, `npm`, `pnpm`, `bun`, `yarn` or `vp`).

## Shell completions

Print a completion script for your shell and add it to your profile:

```bash Terminal
polar --completions zsh
```

Bash, fish and sh are supported too. Run `polar --help` to list every command,
or add `--help` to a command, like `polar products --help`, to see the flags of
every command under it at once.

## Telemetry

The CLI sends one anonymous event per command to help us improve it: the
command name, the names of the flags used (never their values), whether it
succeeded, the duration, the CLI version, your operating system, and whether it
ran in CI or from an AI coding agent. `polar config` commands also report the
config file format, how many entries the file has and would change, and the
codes of any issues found. Events are keyed by a random install id. Access
tokens, organization names and IDs, URLs, webhook payloads and the contents of
your config are never sent.

To opt out, set either variable in your environment:

```bash Terminal
export POLAR_CLI_TELEMETRY_OPTOUT=1
```

The standard `DO_NOT_TRACK=1` is honored as well.
