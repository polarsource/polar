## polar auth login

Sign in to Polar through your browser

```bash
polar auth login [flags]
```

**Flags**

| Flag | Type | Description |
| --- | --- | --- |
| `--sandbox` | `boolean` | Use the sandbox environment |
| `--production` | `boolean` | Use the production environment |
| `--new-session` | `boolean` | Sign in again even if a session is already saved |

**Examples**

Choose sandbox or production, then sign in
```bash
polar auth login
```

Sign in to sandbox
```bash
polar auth login --sandbox
```

Sign in to production again, replacing the saved session
```bash
polar auth login --production --new-session
```

## polar auth token

Create an organization access token for your app and print it as KEY=value lines

```bash
polar auth token [flags]
```

**Flags**

| Flag | Type | Description |
| --- | --- | --- |
| `--scope` | `string` | Scope to preselect on the token page, e.g. products:read. Repeatable. |

**Examples**

Add the token for the active organization to .env.local
```bash
polar auth token >> .env.local
```

Preselect scopes and pipe the variables into a hosting provider without writing them to disk
```bash
polar auth token --scope products:read --scope checkouts:write | fly secrets import
```

## polar auth logout

Sign out and remove saved sessions

```bash
polar auth logout [flags]
```

**Flags**

| Flag | Type | Description |
| --- | --- | --- |
| `--sandbox` | `boolean` | Use the sandbox environment |
| `--production` | `boolean` | Use the production environment |
| `--all` | `boolean` | Remove every saved session |

**Examples**

Sign out, asking which session only if you have both
```bash
polar auth logout
```

Remove every saved session
```bash
polar auth logout --all
```
