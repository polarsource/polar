A **framework adapter** adds Polar routes to your app in a few lines: a checkout route that redirects to a Checkout Session, a Customer Portal route, and a webhook route that verifies signatures and calls your handlers. The JavaScript adapters are built on the [TypeScript SDK](/integrate/sdk/typescript) and use API version `2026-10`.

Better Auth goes further: it creates a Polar customer when a user signs up and links the two with `external_id`. The Laravel adapter is the community-maintained `danestves/laravel-polar` package, not supported by Polar.

## Deprecated adapters

These adapters are deprecated and no longer maintained. For these frameworks, call the [SDK](/integrate/sdk/introduction) directly instead. The [`polar-integration` skill](https://github.com/polarsource/agent-toolkit/tree/main/skills/polar-integration) helps your coding agent migrate.
