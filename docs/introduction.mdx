## Integrate usage-based credits in 5 minutes

```bash Terminal
# Install Polar CLI
curl -fsSL https://polar.sh/install.sh | bash

# Set up the Polar plugin, MCP server and skills for your coding agent
polar agent setup

# Signup, onboard and implement Polar for Billing
claude "Sign up for Polar following https://polar.sh/auth.md, then follow https://polar.sh/docs/quickstart/overview to add usage-based billing with credits to this project: track usage, create products, add a checkout flow, handle webhooks, and gate paid features by subscription and credit balance."
```

Your agent signs itself up through [`auth.md`](/agents/signup) and hands the organization to you with a claim code. See [Build with agents](/agents/overview) for the other ways to connect it.

Prefer to set things up yourself? [Sign up](https://sandbox.polar.sh/start) for a sandbox organization, create your products and meters in the dashboard, and follow the [quickstart](/quickstart/overview).
