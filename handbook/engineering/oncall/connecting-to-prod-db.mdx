title: "Connecting to the Database"
description: "Query PlanetScale Postgres over Tailscale on the private network"
---

All environments run on PlanetScale. Engineer access uses Tailscale.

<Warning>
  These instances hold live data. Confirm the database name before running anything that writes. Use a read replica when you only need to inspect rows.
</Warning>

## Prerequisites

- Tailscale is connected to the company tailnet.
- Access to the database credentials in the Engineering Team vault in 1Password.

## Connect

Find the connection details for each environment (host, port, user, password, and database name) in the Engineering Team vault in the team 1Password. Connect with `psql`, TablePlus, or Postico, and enable SSL (`sslmode=require`).
