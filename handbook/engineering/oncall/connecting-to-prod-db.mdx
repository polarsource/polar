All environments run on PlanetScale. Engineer access uses Tailscale.

<Warning>
  These instances hold live data. Confirm the database name before running anything that writes. Use a read replica when you only need to inspect rows.
</Warning>

## Prerequisites

- Tailscale is connected to the company tailnet.
- Access to the database credentials in the Engineering Team vault in 1Password.

## Connect

Use the hostname for the target environment:

| Environment | Hostname |
| --- | --- |
| Production | `db.internal.polar.sh` |
| Sandbox | `db.internal.sandbox.polar.sh` |
| Test | `db.internal.test.polar.sh` |

Use the user, database name, and port from the matching 1Password entry, with `sslmode=require`. For example:

```bash
psql "host=db.internal.polar.sh port=PORT user=USER dbname=DATABASE sslmode=require"
```

`psql` prompts for the password. TablePlus and Postico take the same connection details; enable SSL and leave SSH tunneling off.
